KASUGAI Canvas Web ガイド

kasugai-canvas-web は、KASUGAI Canvas の描画エンジン（web/ 一式）を GitHub Pages で静的配信する公開ホストです。QGIS プラグイン geo_webview が出力する .kasc + DATA/ プロジェクトを、KASUGAI Canvas 未インストール環境でも ブラウザだけで再生できます。

ステージ（配信チャンネル）

パス内容更新元
stable/安定版（既定の起動先）リリース時に unstable から格上げ
unstable/開発版kasugai_canvas develop の web/
latest/stable/ への互換リダイレクト—

現在の各ステージのバージョンは channels.json を参照してください。

使い方

エンジン URL に ?kasc=<.kasc の URL> を付けて開きます。

https://yamamoto-ryuzo.github.io/kasugai-canvas-web/<stage>/<engine>/?kasc=<url>
例) https://yamamoto-ryuzo.github.io/kasugai-canvas-web/stable/cesium/?kasc=...
geo_webview 側からは「KASUGAI」ボタンや GET :8089/kasugai で、 エクスポート → 登録 → ブラウザ起動までを自動実行できます。

エンジン一覧

Cesium メインエンジン

CesiumJS による 3D 地球儀ビューア。3D Tiles・地形・KML スタイルの3D表現・ FLY（ルート飛行）など、KASUGAI Canvas の全機能を使える主対象エンジンです。 既定エンジンとして使います。

MapLibre

MapLibre GL による高速な 2D ベクター地図ビューア。 QML スタイルの2D再現や属性表示に対応し、平面での閲覧に適しています。

OpenLayers

OpenLayers による 2D 地図ビューア。多様なデータ形式と投影法を扱える 汎用エンジンです。

Leaflet

Leaflet による軽量な 2D 地図ビューア。シンプルな表示・ 軽い動作が求められる場面に適しています。
